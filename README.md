# Lecture to Notes Summarizer

A Python desktop application that converts lecture audio into clean, structured study notes using AI. This tool transcribes audio files and automatically generates organized notes in Markdown format for easier studying and review.

---

## Features

- Upload audio files (MP3, WAV, M4A, MP4, MPEG, WEBM)
- Transcribe lectures using AI (Whisper model)
- Generate structured notes using GPT
- View raw transcript and formatted notes side-by-side
- Export notes as Markdown or text files
- Simple and user-friendly GUI built with Tkinter

---

## Tech Stack

- Python
- Tkinter (GUI)
- OpenAI API (Whisper + GPT)
- Markdown for output formatting
